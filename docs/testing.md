# 测试和异常覆盖

测试分为临时模拟工程的自动化回归，以及官方 GitHub 工程的真实编译验收。自动化检查通过实际 CLI 检查 JSON、退出码和文件状态，工具进程超时额外直接检查进程执行函数。

## 运行回归

```powershell
python tests/test_cli.py
python tests/test_documentation.py
```

需要 Python 3 和 Windows PowerShell 5.1。大多数测试使用临时工程；涉及实际 Keil / ARMCLANG 元数据的检查，在未配置对应本机工具时会标记跳过。测试生成的模拟工程在结束时清理。

## 文档检查

文档回归检查 README、AI 调用说明及维护记录的链接和锚点；检查菜单与 CLI 返回的本地文档路径仍有效；对完整 JSON 配置使用运行时 Schema 校验，并验证 PowerShell 示例语法、入口命名与错误码覆盖。`examples` 中的每份配置都有 README 中对应的完整示例。

## 已覆盖的异常

| 场景 | 检查的结果 |
|---|---|
| 损坏 JSON、缺配置、未知字段、重复 ID | 明确配置错误及非零退出码 |
| 损坏 Keil XML、缺 Target、多 Target | `PROJECT_INVALID` / `TARGET_MISSING` / 明确歧义 |
| 缺工具、手工路径失效、多安装候选 | 缺项或候选列表，显式设置不会被自动替换 |
| ESP-IDF 缺 Python、芯片与 `sdkconfig` 冲突 | 构建前报告环境或配置错误 |
| 缺版本、错误正则、未知模板变量、同名产物 | 拒绝不完整配置 |
| 旧产物存在而本次未生成 | `ARTIFACT_MISSING`，恢复旧文件且不交付 |
| 产物为空或时间过期 | `ARTIFACT_STALE`，恢复旧文件且不交付 |
| 编译子进程失败 | `BUILD_FAILED`、日志保留、旧输出恢复 |
| 进程超时 | 停止进程树、`BUILD_TIMEOUT`、保留终止前输出 |
| 同工程并发 | `PROJECT_BUSY`，先启动的构建仍能完成 |
| 非法动作和参数 | 稳定错误码及非零退出码 |
| 中文、空格、引号和尾反斜杠 | 参数内容及文件结果正确 |
| ESP-IDF 重复构建 | 本次 ELF/BIN 正确重新生成 |
| 升级版本字符串与数值漂移 | 拒绝生成不一致升级镜像 |

## 菜单语言

菜单回归覆盖默认英文、中文首启、`L` 键持久化、重启读取、命令行临时覆盖、环境重新检测后保留偏好，以及两种语言下 `all` / `factory` / `upgrade` 的实际模拟构建和失败提示。非法语言参数返回 `USAGE`，非法本机 `language` 配置返回 `CONFIG_INVALID`。

## 真实编译与故障注入

[公开验收记录](../reports/github-acceptance.md)记录了官方 STM32、GD32、ESP32 示例的 10 项构建组合及固定提交。验收核对 HEX 校验和、ELF 类型、产物 SHA256 和合并镜像分区偏移。在实际 OTA 示例注入 `#error` 后，验证旧应用恢复且没有导出 BIN。

使用准备好的专用临时工作区及工具链配置可重复验收。

```powershell
python tests/accept_github_projects.py --workspace "C:/Temp/puyuan-test" --tools "C:/Temp/puyuan-test/tools.json"
```

具体目录布局、依赖安装和提交号见公开记录。该脚本会真实编译并短暂修改临时示例，务必使用可清理副本。

## 验证边界

常规异常、失败恢复和构建交付已有测试。系统掉电、磁盘写满、强制终止宿主及设备硬件运行尚未做破坏性验证。CubeIDE / PlatformIO 的集成配方需要在相应环境中实际验证。测试通过代表对应主机构建流程及检查条件通过。
